# 🚀 Smart Trader AI - تطبيق الأندرويد ومحرك تحليل الشارتات الذكي

نظام تداول متكامل للأندرويد يعتمد على الذكاء الاصطناعي البصري (Gemini Vision) والتحقق الرياضي من بيانات الأسعار الحقيقية ورادار الأخبار الاقتصادية لمنع التضليل وحماية المتداول.

---

## 🛡️ آلية العمل الهجينة (منع التضليل والهلوسة)
1. **قراءة الشارت (Vision Model):**
   * استخراج اسم الأصل (EURUSD, BTCUSDT, XAUUSD...) والفريم الزمني والنماذج الفنية البصرية (Double Bottom, Bull Flag, Trendlines...).
2. **التحقق الرياضي الصارم (Ground Truth Calculation):**
   * جلب بيانات الشموع الحقيقية (OHLCV) للزوج من السوق المباشر.
   * حساب المؤشرات برمجياً بدقة رياضية 100% (RSI 14, EMA 20/50/200, ATR).
3. **رادار الأخبار والمفكرة الاقتصادية (News & Economic Radar):**
   * جلب آخر الأخبار وتحليل معنويات السوق.
   * فحص الأحداث الاقتصادية العنيفة (الفائدة، التضخم، البطالة) وتفعيل تنبيه عالي الخطورة.
4. **حماية التذبذب (Chop Protection):**
   * إجبار وضع **"الانتظار (Wait / Neutral)"** إذا كان السوق داخل نطاق عرضي ضيق لحماية رأس المال، وعدم توريط المتداول في صفقات خاسرة.

---

## 📱 مميزات تطبيق الأندرويد (Mobile App)
* **واجهة Cyber-Fintech داكنة واحترافية:** مستوحاة من منصات التداول العالمية.
* **التقاط أو رفع لقطة الشاشة:** من المعرض أو الكاميرا مباشرة.
* **تأكيد المعطيات:** إمكانية كتابة الزوج أو الفريم يدوياً في حال كانت الصورة منخفضة الجودة لضمان دقة 100%.
* **عداد التوافق (Confluence Meter):** نسبة مئوية بصرية لمستوى ثقة الصفقة.
* **بطاقة الصفقة المتكاملة:**
  * سعر الدخول (Entry).
  * وقف الخسارة الإجباري (Stop Loss) ومستوى إبطال التحليل (Invalidation Level).
  * الأهداف الأول والثاني (Take Profit 1 & 2).
  * نسبة العائد للمخاطرة (Risk to Reward Ratio).
* **حاسبة إدارة رأس المال (Risk / Lot Size Calculator):** لحساب حجم اللوت وأقصى خسارة مسموحة بناءً على حجم محفظة المستخدم ونسبة المخاطرة (1%-5%).
* **سجل التداول (Trading History):** حفظ كافة الشارتات والتحليلات السابقة محلياً لمراجعتها لاحقاً.

## ⚡ كيفية التشغيل السريع

### 1. تشغيل الخادم الخلفي (Backend)
انقر مرتين على ملف:
```text
start_backend.bat
```
أو عبر التيرمينال:
```powershell
cd backend
.\venv\Scripts\activate
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
> **ملاحظة لاختيار مفتاح الذكاء الاصطناعي:**
> يمكنك تعيين مفتاح Gemini الخاص بك عبر كتابة الأمر التالي في التيرمينال قبل التشغيل:
> `set GEMINI_API_KEY=your_key_here`

### 2. تشغيل تطبيق الأندرويد (Flutter)
انقر مرتين على ملف:
```text
run_app.bat
```
أو عبر التيرمينال:
```powershell
cd mobile_app
flutter run
```
